Privacy Policy

Hermes Agent — personal Google Workspace integration. Last updated: 18 November 2026.

This policy describes how the personal application published at this domain (the "Application") handles Google user data. One individual, its owner, runs the Application for their own use, and it connects only that owner's own Google Account.

1. What the Application accesses

After the owner grants consent: Google Drive files and metadata; Google Calendar calendars and events; Google Sheets spreadsheets and Google Docs documents; Google Tasks task lists and tasks; and, read-only, the owner's YouTube channel information and YouTube Analytics reports. Access is limited to the scopes shown on the Google consent screen. The Application does not access Gmail, Contacts or any other Google service.

2. How the data is used

Only to carry out tasks the owner explicitly requests. Not for advertising, marketing, profiling or creditworthiness. Not used to train, develop or improve generalized AI or machine-learning models.

3. How the data is stored

The Application runs on a server the owner administers. The only long-lived credential it stores is the OAuth refresh token, kept in a local file readable only by the Application's account on that server. No Google account password is ever stored. Task output may be saved on that server under the owner's control.

4. Sharing and disclosure

To complete a request, the Google data that request needs is sent to the AI model provider the Application is configured to use, which processes it under its own API terms. Apart from that, Google user data is never sold, rented or shared with third parties, and is not disclosed to anyone except the owner. The Application has no other users.

5. Retention and deletion

Access can be revoked at any time at myaccount.google.com/permissions, which invalidates the stored token immediately, or by deleting the local token. Once access is revoked, the Application stops retrieving Google user data.

6. Security

Authorization uses the OAuth 2.0 authorization code flow with PKCE. Tokens are stored with owner-only file permissions and are sent only to Google's own API endpoints. The Application requests only the access needed for the tasks it performs.

7. Limited Use disclosure

Hermes Agent's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. Children and other users

The Application is a personal tool for a single adult owner. It is not directed at children and nobody other than its owner can use it.

9. Changes and contact
