Privacy Policy

Hermes Agent — personal Google Workspace integration. Last updated: 18 November 2026.

This policy describes how the personal application published at this domain (the "Application") handles Google user data. The Application is operated by and for a single individual, its owner, and connects only that owner's own Google Account.

1. What the Application accesses

After the owner grants consent, and nothing else: Google Drive files and metadata; Google Calendar calendars and events; Google Sheets spreadsheets and cell contents; Google Docs documents the owner directs it to. Access is limited to the scopes shown on the Google consent screen.

2. How the data is used

Solely to carry out tasks the owner explicitly requests. Not for advertising, marketing, profiling or creditworthiness. Not to train machine-learning models, and not to develop, improve or train generalized AI or machine-learning models.

3. How the data is stored

The Application runs on hardware the owner controls; Google user data is processed in transit and is not copied to any third-party server operated by the Application. The only long-lived credential stored is the OAuth refresh token, kept in a local file on the owner's own machine and readable only by the owner. No Google account password is ever stored. Task output may be written to the owner's local disk and remains under the owner's control.

4. Sharing and disclosure

Google user data is never sold, rented or shared with third parties, and is not disclosed to anyone except the owner. The Application has no other users. Where a task requires contacting an AI model provider, only the content the owner's request requires is sent to that provider under its own API terms; file contents are not sent unless the owner's request requires it.

5. Retention and deletion

Access can be revoked at any time from the owner's Google Account at myaccount.google.com/permissions, which invalidates the stored token immediately, or by deleting the local token. No copies of Google user data are retained after access is revoked.

6. Security

Authorization uses the OAuth 2.0 authorization code flow with PKCE. Tokens are stored with owner-only file permissions, are never shared, and are transmitted only to Google's own API endpoints. The Application requests the minimum access needed for the tasks it performs.

7. Limited Use disclosure

Hermes Agent's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. Children and other users

The Application is a personal tool for a single adult owner. It is not directed at children and is not usable by anyone other than its owner.

9. Changes and contact

Any revision is published at this URL with a new date. Questions: zadhalireza@gmail.com.
