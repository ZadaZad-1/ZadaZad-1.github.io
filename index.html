Hermes Agent

Personal Google Workspace integration

p>

This site exists to describe and support a personal, single-user application: a self-hosted Hermes Agent instance belonging to this site's owner, connected to that same owner's own Google Account so the agent can carry out tasks the owner asks it to perform.

What the application does

The application authorizes access to one Google Account — its owner's — and then, only on the owner's explicit request, uses these Google APIs on that account's behalf:

  • Google Drive API — search for and read files the owner asks about, upload or download files at the owner's direction, and manage folders the owner names.
  • Google Calendar API — read the owner's calendar and create, update, or delete events the owner asks for.
  • Google Sheets APIstrong> — read and update spreadsheets the owner points it at.

Who uses it

Only the owner of this site and of the connected Google Account. The application is not distributed, has no other users, is not offered as a service, and is not available for sign-up. It runs on infrastructure the owner controls.

Data handling

Google user data is not stored on any third-party server and is not shared or sold. The OAuth refresh token that grants access is stored locally on the owner's own machine, and access can be revoked at any time from the owner's Google Account. Full details are in the Privacy Policya>.

Technical details

  • OAuth 2.0 authorization code flow (desktop client) with PKCE, offline access.
  • Access limited to the scopes listed by the consent screen at authorization time.
  • No analytics, no advertising, no tracking cookies, no login on these pages.
