Hermes Agent

Personal Google Workspace integration. A self-hosted Hermes Agent instance run by this site's owner and connected to that same owner's own Google Account, so the agent can do tasks the owner asks for.

What this application does

Only when the owner asks, it uses the Google Drive API (find, read, upload and download the owner's files), the Google Calendar API (read the owner's calendars; create, update and delete events), the Google Sheets API and Google Docs API (read and update the owner's spreadsheets and documents), the Google Tasks API (read and manage the owner's task lists), and the YouTube Data and YouTube Analytics APIs (read-only: view the owner's channel and its reports).

Who uses it

One person: the owner of this site and of the connected Google Account. It is not distributed, has no other users, is not offered as a service, and has no sign-up.

Data handling

To complete a request, the Google data that request needs is processed by the AI model provider the agent is configured to use, under that provider's API terms. Google data is never sold, never used for advertising, and never shared with anyone else. Access can be revoked at any time from the owner's Google Account. Full details: Privacy Policy.
