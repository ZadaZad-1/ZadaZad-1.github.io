Hermes Agent

Personal Google Workspace integration. A self-hosted Hermes Agent instance belonging to this site's owner, connected to that same owner's own Google Account, so the agent can perform tasks the owner asks it to.

What this application does

Only on the owner's request, it uses the Google Drive API (find, read, upload and download the owner's files), the Google Calendar API (read the owner's calendars; create, update and delete events), and the Google Sheets API (read and update the owner's spreadsheets).

Who uses it

One person: the owner of this site and of the connected Google Account. It is not distributed, has no other users, is not offered as a service, and has no sign-up.

Data handling

Google user data is not copied to any third-party server, is never sold or shared, and access can be revoked at any time from the owner's Google Account. Full details: Privacy Policy.
